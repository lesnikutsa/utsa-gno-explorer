# UTSA Gno.land Explorer v1.0.0 — Topaz

## Overview

v1.0.0 is the first stable Topaz (`topaz-1`) release of this independent explorer and
infrastructure project. It combines continuous PostgreSQL indexing, a read-only API, and a
responsive React frontend. It does not claim official Gno.land ownership or endorsement.

## Explorer features

Explore the live overview, indexed blocks and block details, transactions, account pages
with paginated history, validator lists and profiles, Governance, and observed network
distribution. Global search resolves supported heights, hashes, accounts, and validators.

## Transaction improvements

Transactions have human-readable summaries, execution status, gas usage, and errors. Gno
messages are decoded. Bounded `MsgCall` argument values are decoded on demand from stored
raw transaction data, avoiding unbounded response work while retaining inspectability.

## Validator and Governance features

Validator profiles combine official Valopers metadata with voting power, signing history,
and missed blocks. Governance views expose proposals and votes. Network distribution
summarizes peers observed through healthy RPC sources.

## Infrastructure and reliability

The sequential indexer persists normalized data in PostgreSQL 16 while the API uses a
separate read-only role. Multi-RPC health tracking supports safe failover. Backup,
Governance, Valopers, and network-distribution services are operator-visible systemd jobs;
the static responsive frontend is published to Nginx independently.

## Installation

Use [Fresh production installation](../install.md). Choose full history from height 1 or a
new empty current-state deployment from a fixed recent finalized height.

## Upgrade notes

Use [Production update](../update.md). Existing deployments that explicitly set a version
in `/etc/utsa-gno-explorer/api.env` must manually set `API_VERSION=1.0.0` and restart only
`utsa-gno-api.service`. Git updates, migrations, restarts, tags, and deployments are never
automatic.

## Known scope

- The Explorer indexes only from its configured bootstrap height.
- A fresh deployment without a database restore has no earlier history.
- Network distribution is an observed sample, not a complete network census.
- Token metadata and Realm/package pages are future work.
