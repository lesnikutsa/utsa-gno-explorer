# Changelog

## v1.0.0 — 2026-08-01

First stable UTSA Gno.land Explorer release for Topaz (`topaz-1`). It brings continuous
PostgreSQL indexing, read-only exploration APIs, responsive block/transaction/account and
validator views, decoded transaction data, Governance, observed network distribution,
global search, resilient multi-RPC operation, and operator-controlled backup/deployment
services. Documentation is reorganized into installation, update, restore, operations, and
exhaustive-reference layers. See [the full release notes](docs/releases/v1.0.0.md).
